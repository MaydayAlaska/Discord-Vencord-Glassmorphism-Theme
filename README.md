On Linux, to achieve blur and rounded corners on GNOME:

1. Install the [Blur My Shell](https://extensions.gnome.org/extension/3193/blur-my-shell/) extension.
2. Install the helper script [`gnome-rounded-blur`](https://github.com/aunetx/blur-my-shell/blob/master/scripts/GUIDE.md#gnome-rounded-blur-helper-script) (available on the AUR).
3. Configure the extension settings as shown below:
<img width="646" height="1020" alt="Blur My Shell settings" src="https://github.com/user-attachments/assets/3b743746-d445-421e-8425-bd13e8a5d9b6" />

> [!TIP]
> Adjust **Sigma** (blur intensity) and **Corner Radius** to your preference.
